## 📖 Sobre el torneo

La **Copa Algoritmia** es un torneo de programación organizado por **UADE** y **PwC Argentina**, orientado a estudiantes de primer año que cursan materias introductorias de programación. La competencia propone una serie de desafíos con problemas reales que deben resolverse en **Python**, poniendo a prueba tanto la lógica algorítmica como la capacidad de trabajar en equipo bajo presión.

Esta es la **quinta edición** del torneo.

## ▶️ Cómo ejecutar los desafíos

Todos los ejercicios están desarrollados en **Python 3** y no requieren dependencias externas. Solo hace falta tener Python instalado:

```bash
# Clonar el repositorio
git clone https://github.com/mazzitellilean-beep/copa-algoritmia.git
cd copa-algoritmia

# Ejecutar un desafío (ejemplo: desafío 1)
python primer_desafio.py
```

> El segundo desafío requiere un archivo de entrada "partidos.txt" pero en el caso de no tenerlo, se generará uno automáticamente (el archivo generado estará vacío así que asegurate de rellenarlo antes de volver a intentar)
